# Getting help with GuildOS

## Before you ask

- Read the [README](README.md) and the guides in [`docs/`](docs/), especially [studio setup](docs/studio-setup.md) and [production deployment](docs/deployment.md).
- Search [existing issues](https://github.com/S07K/guildos/issues?q=is%3Aissue) and [Discussions](https://github.com/S07K/guildos/discussions).

## Where to go

| You want to… | Go to |
| --- | --- |
| Ask a question about setup, self-hosting or usage | [GitHub Discussions → Q&A](https://github.com/S07K/guildos/discussions) |
| Share an idea or show what you built | [GitHub Discussions](https://github.com/S07K/guildos/discussions) |
| Report a reproducible bug | [Bug report](https://github.com/S07K/guildos/issues/new?template=bug_report.yml) |
| Request a feature | [Feature request](https://github.com/S07K/guildos/issues/new?template=feature_request.yml) |
| Report a security vulnerability | [Private advisory](https://github.com/S07K/guildos/security/advisories/new) — see [SECURITY.md](SECURITY.md) |

GuildOS is maintained in spare time, so responses are best-effort. Please never post API keys, `.env` values or other secrets in issues or discussions.
