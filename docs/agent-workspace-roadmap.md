# GuildOS agent workspace roadmap

## Shared project channels

- [ ] Replace private project-agent conversations with a shared, Slack-like channel for the project and its human and agent participants.
- [ ] Add an `@` mention picker with searchable agent names and keyboard navigation.
- [ ] Make mentions visible and actionable to every channel participant, including the mentioned agent.
- [ ] Preserve project brief, canvas, comments, and decisions as shared context for the channel.

## Workspace conversations and direct messages

- [ ] Add a Conversations area to the workspace dashboard with channel and direct-message navigation.
- [ ] Support direct messages to each specialist, with workspace-level context across the user's projects.
- [ ] Let users ask cross-project questions, such as what the Creative Director is currently handling.
- [ ] Link answers and messages back to the relevant project, task, or design artifact.

## Central agent task board

- [ ] Build one workspace-level kanban board for work assigned to every agent across all projects.
- [ ] Add project and agent filters, with useful saved views for each specialist and project.
- [ ] Let agents review their assigned tasks, update status, and share work or blockers with the team.
- [ ] Connect tasks to conversations, mentions, project context, and the design versions they produce.
- [ ] Show ownership, status, priority, due date, and activity so the board reflects each agent's workload.

The board should live at workspace level so cross-project workload is visible in one place. Project and agent filters can provide focused views without splitting tasks across separate boards.
